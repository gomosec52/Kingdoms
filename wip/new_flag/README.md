## Что исправлено в ветре
Раньше Top / Middle / Bottom крутились отдельно → баннер рвался, иконка разъезжалась.

Теперь цепочка костей:
`Banner → TopSeg → MidSeg → BotSeg`
- обе половины иконки сидят в **MidSeg** вместе
- только мягкие повороты, без сдвигов
- низ качается чуть сильнее верха (каскад)

Файл анимации: `model_wind.gltf` (`banner_wind`, 2 сек loop).
