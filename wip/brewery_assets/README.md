## Согласованная логика (не код)

- Одна кнопка на 2-й странице → общий магазин (вариант **Б**).
- 1 пивовар + 1 винодел на поселение; уровень **1–5 на поставленном блоке**; апгрейд только если блок стоит.
- Права: **от Рыцаря и выше** (все, кроме Крестьянина) — покупка, апгрейд, использование.
- Пиво: ведро воды + сахар + бутылка воды; 7 мин; один процесс.
- Вино: ведро воды + мёд + сладкие ягоды; те же стадии UI.
- Кнопки «Пивоварня N ур» / «Виноделие N ур» — **только отображение** уровня.
