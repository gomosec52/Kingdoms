# Kingdoms Wars Bedrock Add-on

Два дополняющих аддона:

| Файл | Назначение | Script API |
| --- | --- | --- |
| `KingdomsWars.mcaddon` | Поселения, флаг, меню, войны, альянсы | **1.17.0** (стабильное размещение) |
| `KingdomsPrefixes.mcaddon` | Префиксы в чате и над головой | **2.8.0-beta** (как UpRanks+: chatSend → cancel → sendMessage) |

Они читают одни и те же данные мира (`kingdoms:data:v1`) и работают вместе.

## Установка (оба аддона)

1. Установите **оба** файла: `KingdomsWars.mcaddon` и `KingdomsPrefixes.mcaddon`.
2. В мире включите оба behavior pack (+ resource pack Kingdoms Wars).
3. Обязательно включите **Beta APIs** в настройках мира.
4. **Выключите** другие чат-ранк аддоны (UpRanks, Chat Ranks+ и т.п.) — иначе перехват чата конфликтует.
5. Перезайдите в мир.

### Формат ника

`Ник "НазваниеПоселения" "Роль"` — и в чате, и над головой.

Пример: `ARTIK1709 "Север" "Войт": привет`

### Префиксы

| Роль | Префикс |
| --- | --- |
| Создатель деревни | Староста |
| Большая деревня | Войт |
| Городок | Посадник |
| Большой город | Бургомистр |
| Замок | Кастелян |
| Королевство | Король |
| Империя | Император |
| Новый житель | Крестьянин (по умолчанию) |

Создатель меняет префиксы жителей в меню флага → «Префиксы».

Исходники второго аддона: `prefixes_behavior_pack/`.

## Совместимость

Манифесты выставлены под `min_engine_version: [1, 26, 20]`, как в запросе. Если ваша Bedrock-сборка требует другой версии модулей Script API, измените зависимости `@minecraft/server` и `@minecraft/server-ui` в `behavior_pack/manifest.json` под версию вашей игры.

## Как использовать

1. Скопируйте `behavior_pack` и `resource_pack` в папки `behavior_packs` и `resource_packs` Minecraft Bedrock (или поставьте `.mcaddon`).
2. Подключите пакеты к миру + `Kingdoms Prefixes`.
3. Включите Beta APIs.
4. Скрафтите флаг поселения:
   - 3 белой шерсти сверху;
   - палка в центре;
   - изумруд снизу.
5. Возьмите с собой 15 изумрудов.
6. Кликните предметом флага по земле и введите название поселения. Если изумрудов не хватает или создание отменено, предмет флага не тратится.

## Реализованные механики

### Флаг и надпись

- Флаг — кастомный предмет и entity-моб `kingdoms:flag`, а не блок.
- При клике предметом флага по земле создаётся поселение и ставится entity-флаг.
- Над флагом отображается name tag самой entity:
  - тип поселения и название;
  - префикс создателя и ник;
  - HP флага и мораль.
- Во время войны враги бьют флаг как моба. Без объявленной войны урон по флагу не засчитывается.

### Меню флага

При взаимодействии с флагом открывается меню Script UI:

- информация о поселении;
- улучшение типа поселения;
- жители: добавить / исключить игрока;
- префиксы жителей;
- справка о префиксах;
- создание альянса;
- объявление войны;
- сбор налога;
- расформирование поселения с подтверждением.

Главное меню флага стилизовано через JSON UI resource pack:

- `resource_pack/ui/_ui_defs.json`
- `resource_pack/ui/server_form.json`
- `resource_pack/textures/ui/kingdoms/*`

Интерфейс открывается почти на весь экран, использует пергаментный средневековый фон, уменьшенный текст, левую колонку с информацией о поселении и правую сетку действий с иконками. Остальные вспомогательные формы Bedrock, где нужен ввод текста или выбор из списка, остаются стандартными, потому что Script API передаёт их как обычные modal forms.

### Типы поселений

Создание деревни стоит 15 изумрудов.

| Тип | HP | Радиус территории | Налог | Цена улучшения до этого типа |
| --- | ---: | ---: | ---: | ---: |
| Деревня | 120 | 35 | 4 изумруда | 15 изумрудов за создание |
| Большая деревня | 180 | 55 | 8 изумрудов | 80 изумрудов |
| Городок | 260 | 80 | 14 изумрудов | 180 изумрудов |
| Большой город | 380 | 115 | 22 изумруда | 400 изумрудов |
| Замок | 560 | 150 | 32 изумруда | 800 изумрудов |
| Королевство | 780 | 220 | 44 изумруда | 1500 изумрудов |
| Империя | 1100 | 300 | 64 изумруда | 2500 изумрудов |

### Альянсы

- Создатель поселения выбирает другое поселение.
- Создатель выбранного поселения должен быть онлайн и принять предложение.
- После принятия инициатор вводит название альянса.
- В чат отправляется общее оповещение.
- Территории участников альянса считаются объединёнными для доступа жителей.

### Войны

- Войну можно объявить поселению равного типа, на один тип ниже или на один тип выше.
- Победа достигается повреждением и уничтожением флага врага.
- Проигравшее поселение распадается.
- Победитель получает расширение территории на 1/5 радиуса побеждённого поселения.
- Если расширение невозможно из-за чужой территории, создатель победителя получает награду изумрудами.
- Бывшая территория проигравшего на 5 минут становится зоной мародёрства: ломать блоки и открывать хранилища там могут только победители.
- После истечения 5 минут временная зона очищается.

### Налоги

- Налог зависит от типа поселения.
- Забрать налог может только создатель поселения.
- Кулдаун: 25 минут.

### Защита территории

На чужой территории игроки без доступа:

- не могут ломать блоки;
- не могут ставить блоки;
- не могут открывать сундуки, бочки, шалкеры;
- не могут нажимать кнопки и рычаги;
- не могут наносить урон игрокам без войны между поселениями.

Во время войны враг может атаковать игроков и флаг, но всё ещё не может ломать постройки или открывать хранилища.

### Мораль

Мораль пересчитывается раз в игровой день.

Плюсы:

- достаточно игроков для замка и выше;
- нет активной войны;
- есть альянс;
- улучшение поселения сразу добавляет мораль.

Минусы:

- мало игроков для замка и выше;
- идёт война;
- флаг сильно повреждён.

Если мораль падает до 0, поселение распадается.

## Замена модели флага

Временная модель находится здесь:

- `resource_pack/models/blocks/kingdom_flag.geo.json`
- `resource_pack/textures/blocks/flag_placeholder.png`

В Blockbench экспортируйте модель с идентификатором `geometry.kingdoms_flag` или обновите ссылку в:

- `resource_pack/entity/kingdom_flag.entity.json`
- `resource_pack/render_controllers/kingdom_flag.render_controllers.json`

## Упаковка в `.mcaddon`

Можно заархивировать содержимое так, чтобы внутри архива были папки `behavior_pack` и `resource_pack`, затем переименовать архив в `KingdomsWars.mcaddon`.
